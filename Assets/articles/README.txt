ARTICLE ASSETS
==============
Each article gets its own sub-folder named after the article's `slug` in articles.config.js

Example:
  Assets/articles/apex-governor-limits-debug/error-screenshot.png
  Assets/articles/apex-governor-limits-debug/fix-code.png

Reference in articles.config.js like:
  images: [
    { src: "Assets/articles/apex-governor-limits-debug/error-screenshot.png", caption: "Error in debug log" }
  ]

Supported formats: jpg, jpeg, png, gif, webp, svg
